Personal Etsy Research Tool

This website provides information about a personal research application developed for analyzing publicly available Etsy listing data.

Purpose

The application is intended for personal research and trend analysis. It uses publicly available Etsy listing information through the official Etsy Open API.

Data Usage

The application does not sell, share, or transfer Etsy data to third parties.

Contact

For questions about this application, please contact the developer through this GitHub repository.
